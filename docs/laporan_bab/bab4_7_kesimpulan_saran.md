## 4.7 Kesimpulan dan Saran

### 4.7.1 Kesimpulan
1. Sistem deteksi objek 4 kelas (`person`, `bottle`, `laptop`, `cell phone`) dan estimasi kedalaman monokular berbasis **YOLO26n-Depth** berhasil diimplementasikan dan dijalankan pada lingkungan **aplikasi desktop berbasis PyTorch di VS Code / Terminal**.
2. Pada evaluasi **1 seed (`seed=42`)** di *held-out test split* (275 citra: 200 SUN RGB-D + 75 MS COCO, resolusi `384×640`), model **+Attention** (`YOLO26nDepth` dengan `C2PSA` L10 dan `C3k2 attn=True` L22, Epoch 56) mencatat `mAP@0.5 = 30,87%`, `mAP@0.5:0.95 = 17,96%`, `Recall = 78,62%`, `Depth MAE = 0,533 m`, `RMSE = 0,742 m`, dan $\delta_1 = 60,61\%$.
3. Dibandingkan **Baseline Tanpa Attention** (`YOLO26nDepthNoAttn`, Epoch 33: `mAP@0.5 = 26,54%`, `mAP@0.5:0.95 = 13,97%`, `Recall = 77,51%`, `Depth MAE = 0,543 m`, $\delta_1 = 58,42\%$), modul *attention* `C2PSA` + `n22 attn` memberikan kenaikan `mAP@0.5` sebesar `+4,33` poin dan penurunan tipis `Depth MAE` sebesar `-0,010 m` dengan *trade-off* `+333.952` parameter (`+9,46%`) dan `+1,85 ms` pada GPU `480×640` (`9,63 ms` → `11,48 ms`, tetap `87,1 FPS`). Karena evaluasi baru dilakukan pada 1 *seed* dan *test set* kecil (36 bbox `cell phone`, 48 bbox `laptop`), hasil ini belum dapat dinyatakan signifikan secara statistik. Pengujian fisik langsung menggunakan webcam dan meteran (**Tabel 4.6**) masih berstatus **belum diukur**.

### 4.7.2 Saran Pengembangan
1. **Evaluasi Multi-Seed & Uji Statistik**: Menjalankan pelatihan dan evaluasi minimal **3 *seed*** pada *test set* yang lebih besar agar selisih `mAP` maupun *depth error* antara Baseline dan +Attention dapat diuji signifikansi statistiknya.
2. **Studi Ablasi `COCO_MIX` (`0 / 0,3 / 0,5`) dan Penanganan *Class Imbalance***: Melakukan eksperimen variasi rasio pencampuran COCO serta *oversampling* / *copy-paste augmentation* khusus kelas `cell phone` (hanya 36 bbox uji) dan `bottle` untuk meningkatkan `AP@0.5` objek kecil.
3. **Pengukuran Fisik *Real-Time* & *Multi-Point ROI***: Menjalankan `scripts/capture_compare.py` sesuai `docs/checklist_screenshot.md` pada jarak 0,5 m, 1,0 m, dan 2,0 m (kondisi **terang dan gelap**) serta mempertimbangkan *depth sampling* berbasis *mask* atau kuartil bawah untuk mengurangi kesalahan saat *occlusion*.
4. **Generalisasi Lintas Perangkat (Pengembangan Lanjutan)**: Apabila di masa mendatang sistem ingin diporting ke perangkat bergerak (*smartphone*) atau *edge device*, diperlukan tahap lanjutan berupa kuantisasi INT8 dan ekspor ke format runtime *mobile* serta evaluasi latensi langsung pada perangkat target.
